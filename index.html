⚙️ Antes de iniciar

  1. Ir a configuración del computador.
  2. Buscar Opciones Avanzadas.
  3. Activar el Modo para desarrolladores.

🚀 Primeros pasos

  1. Abrir Visual Studio.
  2. Buscar la plantilla en el buscador como WinUi y selecciona la que tenga el símbolo de C# y diga (Empaquetada)
  3. Revisar si tenemos el explorador de soluciones

Explorador de soluciones

Si no lo tenemos, vamos a la barra de herramientas y buscamos Ver y luego Explorador de soluciones

💡 Datos

La plantilla en blanco crea la estructura básica de una app de Windows. El modo de desarrollador deja que Windows ejecute tu app mientras la programas. El explorador de soluciones muestra todos los archivos del proyecto.

📁 Segundo paso: Carpetas y clases.

Carpetas

Crea las carpetas Models y Services, y dentro de cada una, crea las clases correspondientes.

  1. En el explorador de soluciones, haz clic derecho en el proyecto, en este caso "PerfumeriaPIA1", y se nos abrirá una lista con la opción Agregar; luego damos clic en Nueva carpeta
  2. Escribe el nombre de la carpeta como Models
  3. Repite el proceso para crear otra carpeta llamada Services

¿Qué hace?

  • namespace: el nombre del "cajón" donde vive la clase. Debe coincidir con el nombre del proyecto.
  • class Perfume: el molde de un perfume.
  • Id, Nombre, Marca, Precio y Stock: los datos que guarda cada perfume.
  • int: es un número entero, decimal un número con decimales (ideal para precios) y string es texto.
  • {get; set;}: permite leer el dato y escribir un valor.
