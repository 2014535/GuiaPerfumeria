Explorador de soluciones

Si no lo tenemos, vamos a la barra de herramientas y buscamos Ver y luego Explorador de soluciones

💡 Datos

La plantilla en blanco crea la estructura básica de una app de Windows. El modo de desarrolador deja que Windows ejecute tu app mientras la programas. El explorador de solcuiones muestra todos los archivos del proyecto.

📁 Segundo paso: Carpetas y clases.

Carpetas

Crea las carpetas Models y Services, y dentro de cada una, crea las clases correspondientes.

  1. En el explorador de soluciones, haz clic derecho en el proyecto en este caso "PerfumeriaPIA1" le damos click derecho y se nos abrira una lista con la opción Agregar y luego damos click en Nueva carpeta
  2. Escribe el nombre de la carpeta como Models
  3. Repite el proceso para crear otra carpeta llamada Services

  • class Perfume: el molde de un perfume.
  • Id, Nombre, Marca, y Precio, Stock: los datos que guarda cada perfume.
  • int: es un numero entero, double un numero con decimales y string es texto.
  • {get; set;}: permite leer el dato y escribir un valor.
